# Alive Checker
A simple Python CLI tool to check alive subdomains.

## Features

Checks alive hosts
Saves alive domains

## Installation
git clone https://github.com/aryahmpillai/alive-checker.git

cd alive-checker

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt


python3 alive-checker -h

## For Globally run
chmod +x alive-checker

## Usage
alive-checker
